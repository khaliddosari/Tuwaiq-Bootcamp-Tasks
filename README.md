# Tuwaiq Bootcamp

Coursework and projects from the Tuwaiq Academy data science / AI bootcamp, organized by week.

## Contents

| Folder | Topics |
|---|---|
| [python week 1 - 2](python%20week%201%20-%202) | Python fundamentals, error handling & OOP, capstone: training center management system |
| [eda week 3](eda%20week%203) | Pandas, Matplotlib/Seaborn, exploratory data analysis, capstone: NYC Airbnb EDA project |

| [DL week 6](DL%20week%206) | Neural networks, Keras architecture & hyperparameter tuning |

## Running the notebooks

Each notebook is self-contained; open it in Jupyter (or VS Code) with Python 3.12+ and the standard data science stack (pandas, numpy, matplotlib, seaborn, scikit-learn, tensorflow/keras, depending on the week).
